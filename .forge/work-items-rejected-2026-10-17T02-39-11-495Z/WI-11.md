# WI-11: Live acceptance tests — overlay apply/status/request

Target: `tests/acceptance/test_gw_overlay.py` (new).

This WI satisfies the forge acceptance-gate requirement (≥1 WI targeting `tests/acceptance`).

## Acceptance test structure

Requires: `GW_ORG`, `GW_APP_ID`, `GW_APP_INSTALLATION_ID`, `GW_APP_PRIVATE_KEY_PATH`, `GW_CALLER_TOKEN`, `GW_RESOURCE_PREFIX`.

**Pre-requisite**: The test org must have at least one repository with no branch protection rules (direct API push required). This is a documented precondition on org setup (per manifest edge-case dispositions).

Class `TestGwOverlayAcceptance`:

### test_overlay_apply_create_branch_live

1. Create or find a test repo named `{GW_RESOURCE_PREFIX}-overlay-test` with at least one commit, no branch protection.
2. Ensure no `.copier-answers.yml` exists on default branch (delete if present via API).
3. Run `gw overlay apply {GW_RESOURCE_PREFIX}-overlay-test` (wired to apply `python_service` from its `config/repos/` entry).
4. GET `/repos/{org}/{repo}/contents/.copier-answers.yml` — assert 200, content parses as valid YAML with `_module_name: python_service`.
5. Assert no PR exists via GET `/repos/{org}/{repo}/pulls?state=open`.

### test_overlay_apply_unchanged_branch_live

1. Starting from the applied state from above test.
2. Record default branch HEAD SHA via GET `/repos/{org}/{repo}`.
3. Run `gw overlay apply` again with same inputs.
4. GET `/repos/{org}/{repo}` — assert HEAD SHA unchanged.

### test_overlay_apply_update_inputs_live

1. Update `config/repos/{prefix}-overlay-test.yaml` `spec.modules[0].inputs` to change one value.
2. Run `gw overlay apply`.
3. GET `.copier-answers.yml` — assert `_answers` reflects new inputs.
4. Assert HEAD SHA has changed (new commit).
5. Assert no PR.

### test_overlay_status_live

1. Run `gw overlay status {GW_RESOURCE_PREFIX}-overlay-test`.
2. Assert output contains `python_service`, the version, and at least one input key/value.
3. Assert exit 0.

### test_overlay_request_allowed_and_denied_live

1. Ensure policy allows `python_service` for the caller's team, does NOT allow `terraform_module`.
2. Run `gw overlay request --team {team} --repo {prefix}-overlay-test --module python_service`.
3. Assert exit 0; no PR.
4. Run `gw overlay request --team {team} --repo {prefix}-overlay-test --module terraform_module`.
5. Assert exit 1; policy rule name in stderr.
