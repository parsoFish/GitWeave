GitWeave

Schema validation + example module scaffold added — overlay and copier configs now have enforced contracts.

initiative schemas-and-module-scaffold date 2026-10-09 gate ✓ green after

What changed

Before this initiative, GitWeave carried no machine-readable contracts for overlay configs or copier modules — contributors could add a config/ overlay or modules/*/copier.yaml with any shape and nothing caught it. This initiative introduced schemas/overlay.schema.json, schemas/copier-module.schema.json, and a matching modules/example-template/ scaffold, wiring them to the pytest gate so every future addition is validated automatically on push.

The evidence below is captured at two commits: baseline (parent of the PR head, schemas absent) and after (PR head, schemas + module present). The gate that was red on the baseline is green after.
